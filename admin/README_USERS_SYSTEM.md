# Система управления пользователями и ролями

## 🚀 Установка

### 1. Создание таблиц в базе данных

Выполните SQL скрипт `create_users_roles_tables.sql` в вашей базе данных MySQL:

```sql
-- Скопируйте и выполните содержимое файла create_users_roles_tables.sql
```

### 2. Тестовые пользователи

После выполнения SQL скрипта будут созданы тестовые пользователи:

| Логин | Пароль | Роль | Описание |
|-------|--------|------|----------|
| admin | admin123 | Администратор | Полные права доступа |
| editor | editor123 | Редактор | Управление контентом |
| user | user123 | Пользователь | Только просмотр |

### 3. Доступ к системе

1. Откройте `admin/login.php`
2. Войдите с любым из тестовых аккаунтов
3. В админке появится новая карточка "Пользователи"

## 🆘 Решение проблем

### Ошибка "mysqli_num_rows() expects parameter 1 to be mysqli_result, bool given"
- **Причина:** Таблицы не созданы в базе данных
- **Решение:** Выполните SQL скрипт `create_users_roles_tables.sql`

### Ошибка "Table 'database.users' doesn't exist"
- **Причина:** Таблица пользователей не создана
- **Решение:** Проверьте выполнение SQL скрипта

### Не отображается карточка "Пользователи" в админке
- **Причина:** Ошибка в получении статистики
- **Решение:** Убедитесь, что все таблицы созданы корректно

При возникновении проблем:

4. Убедитесь, что все таблицы созданы
